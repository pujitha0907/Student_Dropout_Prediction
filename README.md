# Student Dropout Prediction and Academic Success Analysis

## Project Description

This project uses Data Science and Machine Learning techniques to analyze student information and predict academic outcomes.

The model classifies students into three categories:

* Dropout
* Enrolled
* Graduate

## Problem Statement

To analyze student academic, demographic, and socioeconomic information and predict student academic outcomes using Machine Learning.

## Dataset

Dataset Name: Predict Students' Dropout and Academic Success

Dataset Source: UCI Machine Learning Repository

Number of Records: 4424

Number of Input Features: 36

Target Variable: Target

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn

## Data Science Concepts

1. Data Loading
2. Data Analysis
3. Data Cleaning
4. Data Visualization
5. Data Preprocessing
6. Machine Learning
7. Model Evaluation

## Machine Learning Algorithm

Random Forest Classifier

## Model Evaluation

The model is evaluated using:

* Accuracy
* Precision
* Recall
* F1-score
* Confusion Matrix

## Project Files

* dataset: Dataset used for analysis
* code: Complete Python notebook
* results: Graphs and model evaluation results
* report: Project documentation

## Conclusion

The project demonstrates how Data Science and Machine Learning can be applied to educational data to analyze student academic outcomes and support academic decision-making.

## Limitation

The dataset does not contain attendance records. The model predicts academic outcomes using the available student information rather than attendance-based dropout risk.
